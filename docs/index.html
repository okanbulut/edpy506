Start here

Take-home materials for reviewing lectures, looking things up, and starting your own projects. No background beyond the course and no installation are needed: every notebook runs in Google Colab in your browser.

Three ways to use them

  1. After each lecture: read the cheatsheet, try its self-check, then run the matching recipe notebook.
  2. For a project: choose a method with the flowchart, follow the workflow recipe, and adapt a recipe notebook to your data.
  3. To review: test yourself with the cheatsheets' pitfalls and the workflow checklists.

Running a notebook

  1. Click Open in Colab and sign in with any Google account.
  2. Choose Runtime → Run all. Nothing to upload.
  3. Compare your output with each What you should see note.
  4. Edit the Change these parameters cell and run again.

The ML workflow recipe

Every project follows the same seven steps. The recipe paper has a checklist for each step, an example, and pointers to the lectures.

  1. Define the problem: the outcome, the inputs available at prediction time, and how you will judge success.
  2. Split the data: hide a test set first; use cross-validation for every choice.
  3. Preprocess: impute, encode, scale, inside a pipeline so nothing leaks.
  4. Baseline: the score of a do-nothing model.
  5. Train and tune: compare models and settings by cross-validation.
  6. Evaluate: once, on the test set, and group by group when people are affected.
  7. Interpret: coefficients, importance, SHAP; association is not causation.
